11月8日，Check Point Research 发了一份报告，披露了一个叫 Artex 的黑客团伙。

他们干了一件以前觉得只有好莱坞电影里才会发生的事：用 AI Agent（人工智能代理）批量盗号。

数据很直观。

19 万个游戏账号被盗。

而整个攻击过程的模型成本，不到 400 美元。

你没看错。

不到 400 美元。

这意味着什么？

意味着黑产门槛已经从「需要高深技术的大牛」，下沉到了「只要会买账号就能上手的普通人」。

以前我们总以为，AI 是帮好人提效的工具。

但这件事提醒我们：AI 也是帮坏人自动作恶的杠杆。

01

「 autopilot hacking 」，黑客在开飞机

报告里的名字很形象：Hacking on Autopilot（自动驾驶式黑客攻击）。

传统盗号长什么样？

写脚本、抓包、撞库、人工验证、手动提币。

每一步都要人盯着，效率低，风险高，还要养一群人。

现在呢？

Agent 自己规划步骤。

自己调用工具。

自己判断哪里有空子可钻。

人只需要在旁边看着，或者根本不用看。

Check Point 发现，这个团伙利用的是 AI 模型的「幻觉」和「过度执行」倾向。

他们给 Agent 喂了大量被盗的凭证数据，然后让 Agent 自己去尝试登录、验证、提取。

Agent 不像人类黑客会有「疲惫」或「谨慎」。

它不知道停。

它会一遍遍尝试，直到成功。

而且，攻击速度是指数级提升的。

以前一个人一天能试几百个密码。

现在一个 Agent 一天能跑几万个请求。

400 美元买了多少 API 调用？

够跑完这 19 万次尝试，甚至绰绰有余。

这就是「自动化犯罪」的核心逻辑：

把人力成本，替换成算力成本。

而算力，正在变得极其廉价。

02

你的密码，可能已经「过时」了

很多人听到这儿，第一反应是：

「那我换个大密码不就行了？」

或者：「我再开个二次验证。」

没用。

真的。

这不是技术问题，是认知问题。

以前的攻击是「暴力破解」。

你密码够长够复杂，它就撞不开。

现在的攻击是「智能渗透」。

Agent 会分析你的行为模式。

它会去搜索引擎查你以前泄露过的密码习惯。

它会看你有没有在 Twitter 上公开说过自己玩哪个游戏、用哪个平台。

它会用社会工程学话术去钓鱼，而且语气比真人还自然。

更重要的是：

攻击者不再需要一个完美的病毒。

他们只需要一个「能干活」的 Agent。

这个 Agent 不需要理解代码，它只需要理解「怎么拿到 Token」。

对于游戏账号来说，那个 Token 就是你的全部身家。

皮肤、等级、账号本身的价值，都可能远超 400 美元。

这就是为什么 Check Point 报告里说，这是一个「低风险、高回报」的新赛道。

以前搞技术黑产，得招程序员，成本高，容易被追踪。

现在？

会买 API 额度，会写 Prompt 的黑客，单干就能活。

03

普通用户，该怎么防？

既然攻击已经自动化了，我们靠「谨慎」去防守，已经不够用了。

你得意识到，对面不是一个具体的「人」，而是一堆不知疲倦的算法。

这里有三条建议，不是危言耸听，是底线思维。

第一，账户隔离。

你的游戏账号、社交账号、支付账号，尽量用不同的邮箱注册。

最好加上一层独立的二次验证（2FA），不要用短信验证码，用 Authenticator App 或者硬件 Key。

短信验证码早就被 SIM 卡劫持技术玩坏了。

第二，密码管理器不是可选，是必选。

很多人嫌麻烦，所有网站用一个密码。

这在 AI Agent 面前就是裸奔。

一旦一个库被撞，其他所有站全军覆没。

用 Bitwarden 或者 1Password 这种本地加密的管理器，每个网站一个随机生成的复杂密码。

Agent 再聪明，也猜不出你随机生成的 20 位乱码。

第三，对你的数字足迹保持洁癖。

你在网上晒的「游戏战绩截图」、「登录界面照」、「常用游戏 ID」，都是攻击者的训练数据。

少发。

或者打码。

Agent 最喜欢从这些碎片信息里，拼凑出你的「身份画像」，然后针对性地发起钓鱼。

04

结语：技术中立，但人性有漏洞

说实话，看到 400 美元撬走 19 万账号这个数据，我感到的不是愤怒，而是荒谬。

荒谬在于，我们花了三十年建立的安全体系——密码、验证码、二次确认——在「自主执行」的 AI 面前，正在以惊人的速度失效。

这不是因为技术不够强。

而是因为攻击者的进化速度，远超防御者的想象。

以前我们说「防君子不防小人」。

现在的小人，穿上了一件叫「大模型」的外衣，还会自己写代码、自己找漏洞、自己优化攻击路径。

我们唯一的优势，是「人性」。

Agent 没有人性，所以它不懂「羞耻」，不懂「犹豫」，不懂「放弃」。

但我们有。

我们可以选择不用弱密码。

我们可以选择关闭不必要的社交分享。

我们可以选择多花 10 秒钟验证那个「紧急」的登录提醒。

这些微小的动作，是普通人面对自动化深渊时，最后的盾牌。

别等 19 万账号里有一个是你，才想起这件事。
